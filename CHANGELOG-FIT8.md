# FIT8 update

## Fixed in this update
- Weekly plan cards now open the selected weekday's workout rather than always opening today's list.
- The weekly strip also opens the selected weekday.
- Selected weekday uses its own calendar date key for completion tracking.
- Mobile header now exposes the account button; logged-out users can open sign-in/register and logged-in users can sign out.
- Returning to the Today tab from the main navigation resets the selected day to the actual current day.
- Removed the old CSS stick-figure illustration and its misleading placeholder disclaimer. The movement card now clearly marks the 3D viewer as pending integration.

## Not yet included
- Verified animated 3D exercise assets and their viewer controls. These require an asset-by-asset licensing and movement-coverage check before integration.
