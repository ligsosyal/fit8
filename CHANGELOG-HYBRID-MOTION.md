# FIT8 Hybrid Motion Update

- Replaced the procedural low-poly stick/mannequin animation viewer with the Workout Motion continuous SVG player for the current FIT8 exercise catalog.
- Added mapped motion IDs for goblet squat, dumbbell floor press, single-arm dumbbell row, dumbbell Romanian deadlift, dumbbell shoulder press, dead bug, reverse lunge, glute bridge, lateral raise, hammer curl, overhead dumbbell triceps extension, and forearm plank.
- Added play/pause, restart, seek timeline, and playback speed controls.
- Added attribution and noncommercial license notice.
- Plank remains an isometric pose by design. Glute bridge animation represents the base movement; the FIT8 exercise adds a dumbbell load.

3D asset integration is intentionally not faked in this update. A production-ready 3D renderer will only be enabled for exercises with a reviewed, licensed, movement-matched asset. The existing procedural low-poly figure was removed from the active viewer because its movement quality was not satisfactory.
